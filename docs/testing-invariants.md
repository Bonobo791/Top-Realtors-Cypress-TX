# Website testing invariants

Oracle rules are recorded independently of the implementation. Ordinary Vitest discovers deterministic regressions, production-logic fast-check properties, file-checker fixtures and actual isolated Astro content rebuilds. The template's property-options helper supplies validated100-run/seed/path controls; its synthetic analytics demo passed8 tests separately and is not claimed as product coverage.

Synthetic fixtures never write external services. State/temporary files are isolated per test; no production credentials are used. Replay only a selected failed property with its emitted seed/path. Scoped Stryker mutates hand-authored contracts with --ignoreStatic; report killed/survivor/no-coverage separately. Error-wording/location equivalents and genuinely missing rules are reviewed explicitly rather than silently ignored. Local tests do not establish live provider/CDN/TLS or ranking results.

Output regression additions: srcset accepts local/HTTP(S) images, rejects mailto/tel/data candidates; rendered ratings must match exact score, survey count/type, subject/scope, platform/source link and both date forms on home and profile. The actual build refuses a symlinked dist before Astro cleanup, and the unrelated target sentinel survives. The real recovery fixture restores checked-in content after a bad edit and rebuilds all seven original routes.
