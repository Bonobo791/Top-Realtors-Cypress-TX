# Environment registry

Adapted from the pinned Site-Bootstrap-ADM registry. No runtime environment variables or provider credentials are required by the static site or Nginx. Public origin/indexing/sponsor are validated source fields in src/content/site.json; changing them requires rebuilding.

| Name                                | Purpose                                | Exposure/stage          | Default                             | Validation/failure                                                                                                          | Owner            |
| ----------------------------------- | -------------------------------------- | ----------------------- | ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ---------------- |
| BUILD_COMMIT                        | Public artifact identity               | Public, Node build only | Git HEAD when available             | Full lowercase40hex or explicit local; invalid/missing archive Git fails                                                    | Builder          |
| SOURCE_COMMIT                       | Docker build marker input              | Public build ARG only   | None; explicit value required       | Missing/invalid fails; approved full lowercase 40-character SHA for release, explicit local for disposable development only | Builder/releaser |
| FC_NUM_RUNS                         | Real property run count                | Test only               | 100                                 | Positive safe integer; invalid fails                                                                                        | Tester           |
| FC_SEED                             | Reproducible properties                | Test only               | Framework-generated seed            | Signed32-bit integer                                                                                                        | Tester           |
| FC_PATH                             | Single-property failure replay         | Test only               | Absent                              | Valid colon-number path plus seed required                                                                                  | Tester           |
| E2E_BASE_URL                        | Already-running built/container target | Test only               | Astro preview http://127.0.0.1:4322 | Reachable approved test target; HTTP failure fails tests                                                                    | Tester           |
| PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH | Optional local test browser            | Test only               | Playwright-installed Chromium       | Missing executable fails; CI installs bundled version                                                                       | Tester           |
| EXPECTED_COMMIT                     | Container smoke SHA expectation        | Test only               | No exact SHA assertion              | Supplied expected value must match marker                                                                                   | Tester/releaser  |
| ASTRO_TELEMETRY_DISABLED            | Disable framework CLI telemetry        | Tooling only            | Set to1 in npm scripts              | Not a browser feature or host setting                                                                                       | Builder          |

Cloud network tooling may supply credential-free HTTP(S) proxy arguments and a build_ca trust certificate through Docker's predefined proxy handling/BuildKit secret. They are optional environment-specific install prerequisites; not application settings, committed credentials or final-image content. No TLS verification is disabled. Do not add provider secrets to Docker ARG/ENV.
